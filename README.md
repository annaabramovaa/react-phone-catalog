# Nice Gadgets - Phone Catalog
An online store catalog for phones, tablets, and accessories, developed with React and TypeScript. Users can browse products by category, filter and sort items, navigate through paginated results, view detailed product pages, and manage their shopping cart and favorites.
## Technologies Used
This project was built using the following technologies:
- React — for building the user interface and reusable components.
- TypeScript — for static typing and improved development experience.
- Vite — for fast development and optimized production builds.
- React Router — for application routing and navigation.
- CSS / SCSS — for styling and responsive layouts.
- JavaScript / TypeScript — for application logic and interactive functionality.
- ESLint — for maintaining code quality and consistent coding practices.
- Prettier — for consistent code formatting.
- Git — for version control.
- GitHub — for repository hosting and collaboration.
## Features 
- Product Catalog: Browse phones, tablets, and accessories in a well-organized product catalog.
- Product Details: View detailed product information, including images, specifications, and prices.
- Product Search: Find products quickly using the built-in search functionality.
- Filtering and Sorting: Filter products and sort them based on different criteria.
- Shopping Cart: Add products to the cart, update quantities, and remove items when needed.
- Favorites: Add products to a favorites list to save them for later.
- Responsive Design: The application is fully responsive and works across desktop, tablet, and mobile devices.
- Interactive UI: Interactive buttons, navigation elements, product cards, and other components provide clear visual feedback.
- Navigation: Easily navigate between the catalog, product details, cart, favorites, and other sections.
- Loading and Error States: Handle loading processes and unavailable data with appropriate UI states.

## Technical Requirements

To run this project, you will need:

- **Node.js** (version 14.x or newer): A JavaScript runtime built on Chrome's V8 JavaScript engine, used for server-side scripting.
- **NPM** (version 6.x or newer): The Node.js package manager, used for managing project dependencies.

## Installation and Setup

To install the project and run it locally, follow these steps:

1. Clone the repository:

    ```
    git clone https://annaabramovaa.github.io/react-phone-catalog/
    ```

2. Navigate to the project directory:

    ```
    cd react-phone-catalog
    ```

3. Install dependencies:

    ```
    npm install
    ```

4. Start the local development server:

    ```
    npm start
    ```
5. Open http://localhost:5173/react-phone-catalog/ in your browser to view the website.
